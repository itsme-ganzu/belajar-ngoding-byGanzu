# Belajar Ngoding dari Nol (dengan Tutor AI)

👉 **Baru pertama kali ke sini dan bingung mulai dari mana? [KLIK DI SINI: BACA FILE INI DULU](BACA-INI-DULU.md) 👈**

> **Status: v1.0 (Lengkap).** Materi dari Level 1 sampai Level 5 sudah tersedia lengkap dari nol hingga deployment.
> Jika ada yang membingungkan atau ingin memberi masukan, silakan buat Issue di GitHub.

## Ini buat siapa
- Orang yang **belum pernah ngoding** dan bingung mulai dari mana.
- Orang yang **udah paham syntax tapi mentok di "terus gue harus ngapain?"** (lihat `PATHWAY.md`, modul Jembatan).

## Ini bukan apa
Bukan kumpulan video tutorial yang nyuapin lu dari nol. Repo ini adalah **‘Sistem Belajar Mandiri Berbasis AI’** (peta + kurikulum materi + sistem prompt tutor AI + tes otomatis). 

Tutor pribadi lu adalah **LLM lu sendiri** (ChatGPT, Claude, Gemini, dll). Cara lu belajar, seberapa aktif lu bertanya, dan seberapa kritis lu menantang AI lu sampai paham—**itu 100% tanggung jawab dan petualangan lu sendiri**.

## Kontrak Belajar
1. Ganzu **TIDAK** membuka sesi tanya-jawab privat.
2. AI adalah guru lu, lu adalah muridnya, repo ini adalah silabus dan pengujinya.
3. Hakim kebenaran kodemu adalah **tes otomatis di terminal**, bukan omongan manis AI.

## Cara mulai (10-15 menit)
1. Download repo ini: tombol hijau **Code → Download ZIP**, lalu extract. (Nggak perlu git.)
2. Buka LLM pilihan lu (Claude, ChatGPT, Gemini, dll), mulai **chat baru**.
3. Buka `TUTOR.md` dan `PATHWAY.md`, salin isinya, tempel ke chat (panduan lengkap: `BACA-INI-DULU.md` atau `CARA-PASANG-TUTOR.md`).
4. Ketik: `Gue mau belajar ngoding. Mulai dari placement.`
5. Tutor bakal nanya level lu dan nyuruh buka modul yang pas.

## Struktur
```
BACA-INI-DULU.md        panduan langkah-demi-langkah ramah pemula
TUTOR.md                prompt sistem tutor AI (tempel di chat)
PATHWAY.md              peta 5 level + gerbang lulus
level-1-foundations/    fondasi Python dasar (1.0 s/d 1.8 + Jembatan)
level-2-building/       software development, pytest, SQLite, Git
level-3-applied-with-ai/ engineering dengan AI, audit keamanan, anti-halusinasi
level-4-specialization/ spesialisasi Data Analyst (SQL, Pandas, Visualisasi)
level-5-shipping/       deployment cloud, portofolio, kontribusi open source
_maintainer/            alat verifikasi tes otomatis repo
```

## Batasan yang jujur
- Tutor AI bisa salah dan bisa "bocor" (ngasih jawaban). Percaya sama **tes otomatis**, bukan omongan AI.
- Tutor nggak punya memori antar chat. Di akhir sesi dia bikin ringkasan, simpan dan tempel lagi di sesi berikutnya.
- Fitur tiap platform AI berubah-ubah. Panduan pasang di sini belum diverifikasi untuk semua platform.
