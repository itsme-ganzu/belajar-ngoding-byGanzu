## 🎓 Gerbang Wisuda (Final Gate): Menjadi Software Engineer
Untuk mengklaim kelulusan penuh dari seluruh program belajar ini:
1. Memiliki minimal **1 proyek publik aktif** di GitHub dengan README standar industri.
2. Memiliki riwayat **minimal 1 Pull Request (PR) yang berhasil dimerge** ke repositori open source (boleh di repo ini sendiri untuk memperbaiki materi/menambah tes, atau repo open source publik lainnya).
