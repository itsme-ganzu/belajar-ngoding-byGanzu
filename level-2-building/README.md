# Level 2: Building (Software Development Fundamentals)

**Outcome:** Lu mampu membangun proyek software utuh yang terstruktur rapi, menggunakan database SQLite, diverifikasi dengan tes otomatis `pytest`, dan terdokumentasi di repositori GitHub pribadi.

---

## Modul Pembelajaran:
1. **[2.1: Modular Code & Virtual Environment](2.1-modular-venv/materi.md)**
   - Import antar file, `__name__ == '__main__'`, isolasi library dengan `venv` dan `requirements.txt`.
2. **[2.2: Testing Otomatis dengan Pytest](2.2-testing-pytest/materi.md)**
   - Prinsip pengujian otomatis, pola AAA (*Arrange-Act-Assert*), menjalankan tes berbasis CLI.
3. **[2.3: Database Lokal SQLite](2.3-database-sqlite/materi.md)**
   - Operasi CRUD (Create, Read, Update, Delete), schema tabel relasional, pencegahan SQL Injection.
4. **[2.4: Version Control dengan Git & GitHub](2.4-git-github/materi.md)**
   - Siklus kerja `git add`, `commit`, `push`, format commit standar, dan membuat repositori publik.

---

## 🏆 Gerbang Lulus Level 2: Proyek Mandiri
Buat satu repositori software mandiri di GitHub lu sendiri dengan kriteria:
1. Kode terbagi minimal 2 file modul (misal `db.py` dan `app.py`).
2. Menggunakan SQLite untuk menyimpan data secara persisten.
3. Memiliki minimal 3 unit test otomatis menggunakan `pytest` dan semuanya lulus hijau (`PASS`).
4. Memiliki `README.md` yang menjelaskan cara install dan menjalankan aplikasi.

Setelah selesai dan link repo GitHub diserahkan ke tutor, lu resmi berhak masuk ke **Level 3: Applied with AI**!
