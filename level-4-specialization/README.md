# Level 4: Specialization (Data Analyst Track)

**Outcome:** Lu mampu mengambil data mentah, membersihkan, menganalisis pola, dan menyajikan insight bisnis nyata menggunakan Python dan SQL.

---

## Modul Pembelajaran:
1. **[4.1: SQL Lanjutan untuk Analisis Data](4.1-sql-analisis/materi.md)**
   - Agregasi `GROUP BY`, `HAVING`, manipulasi multi-tabel `INNER JOIN` dan `LEFT JOIN`.
2. **[4.2: Data Wrangling & Cleaning dengan Pandas](4.2-pandas-cleaning/materi.md)**
   - Struktur DataFrame, imputasi *missing values* (`NaN`), transformasi kolom bisnis.
3. **[4.3: Visualisasi Data (Matplotlib & Seaborn)](4.3-visualisasi-data/materi.md)**
   - Grafik tren waktu, perbandingan kategori (*bar chart*), dan analisis sebaran (*histogram/KDE*).

---

## 🏆 Gerbang Lulus Level 4: Proyek Analisis Dataset Nyata
Ambil satu dataset publik (misal: data transaksi retail atau log keuangan).
Buat analisis data di Jupyter Notebook atau Python script yang mencakup:
1. Pembersihan data (penanganan minimal 1 kolom data kotor/kosong).
2. Tiga grafik visualisasi dengan judul dan sumbu yang jelas.
3. Tiga poin rekomendasi keputusan bisnis tertulis ("Berdasarkan data, promo sebaiknya diarahkan ke kategori X karena...").
4. Upload kode dan laporan hasil ke GitHub.
