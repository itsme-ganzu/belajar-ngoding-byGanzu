# Cara pasang tutor (jalur universal: tempel di chat)

Jalan di LLM mana pun yang punya kolom chat. Belum diverifikasi untuk tiap platform.

1. Buka chat **baru** di LLM pilihan lu.
2. Salin seluruh isi `TUTOR.md` (di folder utama), tempel, kirim.
3. Salin seluruh isi `PATHWAY.md` (di folder utama), tempel, kirim.
4. Ketik: `Gue mau belajar ngoding. Mulai dari placement.`

## Tips
- Percakapan panjang bikin AI lupa aturan. Kalau tutor mulai ngasih jawaban langsung, tempel `TUTOR.md` lagi.
- Setiap mulai modul baru, tempel isi `materi.md` modul itu.
- Di akhir sesi, simpan ringkasan dari tutor. Tempel di awal sesi berikutnya.
- Kalau platform lu punya fitur Project / custom instructions / Gem, tempel `TUTOR.md` di sana supaya aktif di setiap chat. Langkahnya beda per platform, cek di platform lu.

## Kalau tutor "bocor"
Kalau tutor ngasih jawaban penuh padahal lu belum coba, atau muji jawaban salah, bikin Issue dan sebut model yang dipakai.
