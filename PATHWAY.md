# PATHWAY: Peta Belajar (dibaca tutor dan murid)

Aturan: murid **tidak naik level** sebelum lolos gerbang levelnya.
Status materi: ✅ ada | 📝 outline saja (belum ditulis).

## Pintu masuk (placement)
| Kondisi murid | Mulai dari |
|---|---|
| Belum pernah ngoding | Level 1 (modul 1.0) |
| Paham syntax tapi bingung "terus ngapain?" | Modul Jembatan (Level 1) ✅ |
| Sudah bisa bikin program kecil | Level 2 atau 3 (tes dulu) |

Placement itu perkiraan. Kalau ternyata terlalu sulit, turun satu pintu, nggak perlu malu.

## Level 1: Foundations (Python)
Outcome: nulis program kecil sendiri dan bisa jelasin cara kerjanya.

| Modul | Isi | Status |
|---|---|---|
| 1.0 | Setup, apa itu program, jalanin file | ✅ |
| 1.1 | Variabel, tipe data, input/output | ✅ |
| 1.2 | Kondisi dan logika boolean | ✅ |
| 1.3 | Loop | ✅ |
| 1.4 | Fungsi | ✅ |
| 1.5 | List, dict, string | ✅ |
| 1.6 | Baca error dan debugging | ✅ |
| 1.7 | File dan CSV | ✅ |
| 1.8 | Mini proyek (contoh: pencatat pengeluaran dari CSV) | ✅ |
| Jembatan | Dari syntax ke proyek: pecah masalah, pseudocode, scope kecil (MVP), baca dokumentasi, cara keluar dari stuck | ✅ |

**Gerbang:** checkpoint tiap modul + mini proyek tanpa bantuan LLM.

## Level 2: Building ✅
Outcome: proyek utuh yang rapi, bisa dites, ada di GitHub.
Isi:
- 2.1 Modular Code & Virtual Environment (venv, requirements.txt)
- 2.2 Testing Otomatis dengan pytest
- 2.3 Database Lokal SQLite & Relasi Data
- 2.4 Version Control dengan Git & GitHub (commit, push, repo publik)
**Gerbang:** Proyek modular mandiri di GitHub dengan SQLite, minimal 3 tes pytest lulus, dan README jelas.

## Level 3: Applied with AI ✅
Outcome: pakai AI untuk menghasilkan dan merapikan kode tanpa jadi tergantung atau ketipu.
Isi:
- 3.1 Anatomi & Batasan LLM (Halusinasi, Stale API, Zero-Trust AI)
- 3.2 Technical Specification & Context Prompting (Metode R-C-I-E)
- 3.3 Code Review, Audit Keamanan (.env), & Red Teaming AI
**Gerbang:** Ujian audit bug AI (menemukan celah keamanan, logika rusak, dan membetulkannya dengan tes otomatis).

## Level 4: Specialization (Data Analyst Track) ✅
Outcome: mampu mengambil data mentah, membersihkan, menganalisis, dan menyajikan insight bisnis nyata menggunakan Python dan SQL.
Isi:
- 4.1 SQL Lanjutan untuk Analisis Data (GROUP BY, JOIN)
- 4.2 Data Wrangling & Cleaning dengan Pandas (Imputasi NaN, transformasi kolom)
- 4.3 Visualisasi Data (Matplotlib & Seaborn)
- 4.4 Proyek Akhir Analisis Dataset Publik Nyata
**Gerbang:** Laporan analisis data mandiri di GitHub (pembersihan data, grafik visualisasi, dan rekomendasi bisnis).

## Level 5: Shipping & Production ✅
Outcome: deploy aplikasi ke server internet, portofolio profesional, dan kontribusi nyata ke open source.
Isi:
- 5.1 Konfigurasi Deployment & Environment Variables (Prinsip 12-Factor App)
- 5.2 Portofolio GitHub & Etika Kontribusi Open Source (Alur Pull Request)
**Gerbang Wisuda:** 1 proyek publik aktif di GitHub + riwayat minimal 1 Pull Request (PR) yang berhasil dimerge ke repositori open source.
