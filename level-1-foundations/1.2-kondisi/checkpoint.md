1. Kode berikut mencetak apa?
```python
x = 10
if x > 5:
    print("A")
if x > 8:
    print("B")
else:
    print("C")
```
*(Perhatikan: ada dua `if` terpisah, bukan `elif`)*

```python
skor = 95

    print("Lulus")
elif skor >= 90:
    print("Istimewa")
```
Kenapa tulisan "Istimewa" tidak pernah muncul walau skornya 95?
