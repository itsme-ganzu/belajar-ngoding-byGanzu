# Level 1: Foundations (Python)
Outcome: nulis program kecil sendiri dan bisa jelasin cara kerjanya.

Modul yang tersedia:
- **1.0 Setup**: Install Python, terminal dasar, program pertama `Halo, dunia!`.
- **1.1 Variabel**: Tipe data dasar (`int`, `str`, `float`), input/output, operasi hitung.
- **1.2 Kondisi**: Percabangan `if`/`elif`/`else`, logika boolean, perbandingan.
- **1.3 Loop**: Perulangan `for` & `range()`, akumulator, perulangan `while`, `break`.
- **1.4 Fungsi**: Definisi fungsi `def`, parameter/argumen, perbedaan fatal `return` vs `print`.
- **1.5 Data Collection**: Manipulasi `list`, `dict` (key-value), dan string (`.strip()`, `.lower()`, `.split()`).
- **1.6 Debugging**: Membaca Traceback dari bawah, jenis-jenis error umum, teknik print debugging.
- **1.7 File & CSV**: Membaca dan menulis file teks dengan `with open()`, olah data CSV.
- **1.8 Mini Proyek**: Membangun aplikasi CLI pencatat pengeluaran uang terintegrasi CSV.
- **Jembatan**: Dari syntax ke proyek mandiri, teknik dekonstruksi masalah (MVP & pseudocode), keluar dari *stuck*.

Cara belajar tiap modul: tempel `materi.md` ke tutor AI → ngerjain latihan di folder `latihan/` → jalanin tes otomatis `python test_1_x.py` → jawab `checkpoint.md`.
