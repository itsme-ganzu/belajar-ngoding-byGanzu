# Latihan 1.1

Bikin dua file di folder ini.

## Soal 1: `jawaban_1.py`
Program minta **nama** lalu **umur**, lalu menampilkan:
```
Halo, Budi! Tahun depan umur kamu 21 tahun.
```
(Contoh jika input nama `Budi` dan umur `20`.) Umur tahun depan harus dihitung, bukan ditulis manual.

## Soal 2: `jawaban_2.py`
Program minta **harga satuan** lalu **jumlah barang** (keduanya bilangan bulat), lalu menampilkan:
```
Total: 45000
```
(Contoh jika harga `15000` dan jumlah `3`.)

## Tes
Dari folder `latihan`:
```
python test_1_1.py
```
Kalau gagal, jangan langsung minta jawaban ke tutor. Baca pesan error dulu dan ceritakan ke tutor apa yang lu lihat.
