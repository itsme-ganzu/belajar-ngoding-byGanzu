Tebak output tanpa menjalankan program:

1. Kode berikut menghasilkan total berapa di akhir?
```python
total = 0
for i in range(3):
    total = total + i
print(total)
```

2. Temukan bug: kenapa kode berikut TIDAK menghasilkan total 10?
```python
for i in range(5):
    total = 0
    total = total + i
print(total)
```
Apa akibat dari menaruh `total = 0` di dalam badan loop?

3. Apa yang terjadi jika kode berikut dijalankan di terminal?
```python
x = 1
while x < 5:
    print(x)
```
Bagaimana cara memperbaikinya agar loop berhenti saat `x` mencapai 5?

4. Kapan lu sebaiknya memilih `for`, dan kapan lu memilih `while`? Jelasin bedanya dengan analogi kegiatan sehari-hari.
